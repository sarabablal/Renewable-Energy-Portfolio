# Renewable Energy & Data Analytics Portfolio

Welcome to my engineering portfolio. This repository integrates computational data analytics, machine learning, and physical modeling to solve real-world challenges in Renewable Energy systems, focusing on localized applications in Morocco.

## Repository Structure

*   **[ecosolar-advisor/](./ecosolar-advisor)**: A data-driven Python application designed to analyze residential utility bills (MAD), evaluate energy consumption habits, and automatically design tailored solar PV rooftop setups.
*   **[battery-health-tracker/](./battery-health-tracker)**: A numerical simulator that models Lithium-ion EV battery degradation over time, evaluating the accelerated thermal stress caused by high ambient temperatures.
*   **[weather-scraper-ouarzazate/](./weather-scraper-ouarzazate)**: A real-time automation script that scrapes historical and forecasted meteorological data from environmental APIs moped for solar power analysis.
